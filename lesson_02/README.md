# Тема 2. Проект, задача и результат в Битрикс24

Подготовьте в своём портале проект магазина «СЕВЕР», три задачи и результат первой задачи. В репозиторий загрузите семь ключевых скриншотов и заполните [отчёт](report.md). Снимать каждый клик не нужно.

## Что делать

1. Пройдите [практику второй темы](https://maximbytecamp.github.io/algorthimization_course_vvodnoe/upravlenie-programmnymi-proektami/lessons/02-bitrix24/). Пользуйтесь [готовыми текстами](texts.md): названия, цель, условия задач и образец результата уже выписаны.
2. Назначьте задачи своей учётной записи. Выберите актуальные сроки, согласованные с преподавателем, а не даты со снимков урока. Для задачи с проверками срок должен быть не раньше срока подготовки правил, на которые она опирается.
3. Первую задачу начните, сохраните результат сообщением в её чате, проверьте по двум примерам и завершите. Другой участник может оставить отзыв; при индивидуальной работе достаточно честной отметки о самопроверке. Формулировки — в конце [texts.md](texts.md#проверка-результата).
4. Создайте задачи 2 и 3 с полными условиями, исполнителем и сроком. Пока их результаты не подготовлены, оставьте задачи незавершёнными. Для сдачи этой темы не нужно заранее выполнять результаты этих двух задач.
5. Снимите экраны по таблице. Заполните в [report.md](report.md) только места `[[...]]` своими ссылками. Загрузите PNG в `screenshots`, сохраните отчёт и проверьте Actions по [общей инструкции](../README.md#как-сохранить-работу-и-запустить-проверку).

**Если всё не помещается:** закройте лишние панели или увеличьте окно, но не уменьшайте текст до нечитаемого размера. Если нужен дополнительный кадр, оставьте обязательный файл и добавьте продолжение, например `03-result-extra.png`. В отчёт добавьте ссылку на него. Дополнительные файлы допустимы, но не заменяют семь обязательных. Один кадр может показывать несколько признаков; все обязательные имена всё равно сохраняются.

Снимки должны быть вашими, из сохранённых записей вашего портала. Не загружайте картинки урока вместо своей работы. Сохраняйте PNG в исходном разрешении. Перед загрузкой скройте личные данные по [общим правилам](../README.md#безопасность-снимков).

## Как получить свои ссылки

- **Репозиторий:** адрес главной страницы своего репозитория на GitHub, без `/tree/...`.
- **Проект:** откройте проект в Битрикс24 и скопируйте адрес из браузера.
- **Задачи 1–3:** откройте каждую сохранённую задачу. Скопируйте её ссылку через меню карточки, если такой пункт доступен, либо адрес страницы открытой задачи. Ссылка должна вести на конкретную задачу, а не на общий список. Не переносите адреса из примера преподавателя.

Приватная ссылка может требовать входа в портал. Доступ согласовывается отдельно; не публикуйте пароли и не меняйте тип проекта на открытый ради проверки.

## Когда работу можно предъявлять

- [ ] Есть семь читаемых PNG, по ним видны все признаки из таблицы.
- [ ] В отчёте стоят свои пять ссылок, маркеров `[[...]]` не осталось.
- [ ] Результат первой задачи отправлен; два примера проверены; задача завершена.
- [ ] Две следующие задачи поставлены, но не отмечены готовыми без результата.
- [ ] Последний запуск Actions для сдаваемого коммита зелёный.

Отправьте преподавателю ссылку на репозиторий и успешный запуск. **Принятие работы — решение преподавателя по содержанию, а не только зелёный Actions.** Гант, BitrixGPT, платные функции и работающий сайт магазина для этой сдачи не требуются.
